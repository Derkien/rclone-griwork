rclone-griwork

rclone-griwork is a private, personal-use OAuth client used by rclone — a well-known open-source command-line tool — to synchronize a single working folder between the owner's computer and their own Google Drive.

Purpose of the application

The client exists for one purpose only: the owner runs scheduled, one-way rclone copy jobs that mirror their local project folder to their own Drive folder as a personal backup. There is no web service, no other users, and no server component. All processing happens locally on the owner's machine.

What Google account data is accessed

  • OAuth scope requested: https://www.googleapis.com/auth/drive.file — per-file access limited to files created by this application itself. The client cannot read or modify any other files on the Drive.
  • No Google account profile data, contacts, email, or other Google services are accessed.

Who uses it

Exactly one user: the owner of this Google account. This is not a public application and is not offered to any other users.

Compliance

This application does not generate AI-generated content of any kind and does not use Google APIs for any prohibited purposes, including AI-generated non-consensual intimate imagery (AI NCII). See our Privacy Policy.
