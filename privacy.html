Privacy Policy — rclone-griwork

Last updated: November 23, 2026

This Privacy Policy describes how rclone-griwork (the "Application") handles data when used with Google Drive via the Google Drive API.

1. What the Application is

The Application is a private, personal-use OAuth client configuration for rclone, an open-source command-line file synchronization tool. It is used by a single user — the owner of the associated Google account — to copy files from a local folder to their own Google Drive as a personal backup.

2. What Google user data is accessed

  • The Application requests exactly one OAuth scope: https://www.googleapis.com/auth/drive.file (per-file scope). Under this scope the Application can only create and modify files that it created itself. It cannot read, list, or modify any other files or folders on the user's Drive.
  • No other Google APIs, products, or user data (Gmail, Contacts, Photos, profile information, etc.) are requested or accessed.

3. How the data is used

  • Files are copied from the owner's local disk to the owner's own Drive storage at the direction of the owner. The content of the files is chosen entirely by the owner.
  • No profiling, no analytics, no machine learning, no advertising use of data.
  • The Application does not generate AI-generated content and does not use Google APIs for any prohibited purposes, including AI-generated non-consensual intimate imagery (AI NCII).

4. Data storage and retention

  • Copied files are stored in the owner's own Google Drive. The owner can delete them at any time from Drive; the Application does not retain independent copies on any server.
  • The OAuth access and refresh tokens are stored locally, on the owner's computer only (in the rclone configuration file). They are never transmitted to any third party.
  • The Application operator (the account owner) does not operate any server that receives Google user data.

5. Sharing with third parties

No Google user data is sold, shared, transferred, or disclosed to any third party. The Application interacts directly and exclusively with the Google Drive API on behalf of its single user.

6. Data deletion

The owner may revoke the Application's access at any time through their Google Account permissions page, which immediately invalidates all tokens. Files already copied to Drive can be deleted manually at any time.

7. Changes to this policy

This policy may be updated if the Application's behavior changes. The date above reflects the latest revision.
